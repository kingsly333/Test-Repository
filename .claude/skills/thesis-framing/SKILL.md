# Thesis Framing Skill

## Purpose
Help users develop, refine, and frame academic or argumentative thesis statements. This skill guides Claude through structuring a strong, defensible thesis with clear argumentation.

## When to Use
Invoke this skill when the user asks to:
- Write, improve, or critique a thesis statement
- Frame an argument or central claim
- Structure an academic essay or paper opening
- Develop a position or hypothesis

## Process

### 1. Understand the Topic
- Ask for the subject, discipline, and assignment context if not provided
- Identify the scope (broad topic → focused claim)

### 2. Diagnose the Draft (if one exists)
Evaluate against these criteria:
- **Specificity**: Is the claim precise or too vague?
- **Arguability**: Can it be contested? (Not a fact or observation)
- **Scope**: Is it appropriately narrow for the paper length?
- **Roadmap**: Does it signal the paper's structure or main supports?

### 3. Frame the Thesis
Use one of these structures as appropriate:

**Analytical**: `[Subject] [does/reveals/shows] [claim] because [reason 1], [reason 2], and [reason 3].`

**Argumentative**: `Although [counterargument], [subject] [claim] because [evidence/reasoning].`

**Comparative**: `While [A] [characteristic], [B] [contrasting claim], suggesting [broader significance].`

**Interpretive**: `[Text/work] uses [technique] to argue that [interpretation], challenging [assumption].`

### 4. Strengthen the Claim
- Replace weak verbs (is, has, shows) with precise, active verbs
- Add a "so what" — the broader significance
- Ensure the claim is falsifiable and requires evidence to support

### 5. Output Format
Provide:
1. The revised thesis statement (clearly marked)
2. Brief explanation of changes made
3. 2–3 questions the paper will need to answer to support this thesis

## Example

**Weak**: "Social media has effects on teenagers."

**Strong**: "By normalizing comparison-driven validation, social media platforms erode adolescent self-concept formation at a critical developmental stage, making algorithmic design a public health issue rather than a mere product choice."

## Notes
- For non-English papers, apply the same logic in the target language
- For STEM or empirical work, reframe as a hypothesis with testable prediction
- Always confirm the disciplinary conventions before finalizing (MLA, APA, Chicago differ in expectations)
